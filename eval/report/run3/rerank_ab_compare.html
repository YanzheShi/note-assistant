循环内重排 A/B/naive 对照评测

对比列：A / B / C / D — 条形按各指标内相对高低归一化（越长越好）。

A · A · 循环重排开 + 图扩展开（生产默认）
循环内重排 开启（生产默认）。每轮工具调用后，循环内 rerank_loop 节点对累积证据做交叉编码精排并裁剪 top-10，再交给 Judge（reflect）决策。配置 agent_reranker_loop_enabled=True。
B · B · 循环重排关 + 图扩展开（仅出口重排）
循环内重排 关闭。agentic RAG 结构不变，但跳过 rerank_loop（agent_reranker_loop_enabled=False），只在出口 rerank_exit 做一次精排取 top-5。用于隔离「循环内重排」这一环节的增量价值。
C · C · naive 基线（RAGChain）
naive 基线（RAGChain）。传统非 agent 链路：history 串联检索 + 单次生成，无 agentic 循环、无 Judge、无语义缓存。作为对照基线。
D · D · 循环重排开 + 图扩展关（隔离图扩展价值）
循环内重排 开启 + 图扩展 关闭。与 A 唯一差异是关闭 agent_graph_expand_enabled，用于隔离「沿 wikilinks 自动扩展关联笔记」这一环节的增量价值（耗时 / 召回 / 质量）。
